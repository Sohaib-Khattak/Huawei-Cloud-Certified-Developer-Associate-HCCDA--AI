# Huawei-Cloud-Certified-Developer-Associate-HCCDA--AI
Huawei Cloud Certified Developer Associate (HCCDA) - AI
This repository contains my personal notes, hands-on lab files, practice code, and study resources dedicated to preparing for and passing the Huawei Cloud Certified Developer Associate - AI (HCCDA-AI) certification.
📋 Certification Overview
The HCCDA-AI credential validates foundational knowledge and hands-on skills in Artificial Intelligence (AI) and Machine Learning (ML) engineering using Huawei Cloud services. It covers core concepts of deep learning, computer vision, natural language processing (NLP), and the lifecycle of AI development.
🔍 Core Topics Covered
• AI & Machine Learning Foundations: Linear algebra, statistics, Python essentials, and classical ML algorithms.
• Deep Learning (DL): Neural network architectures, activation functions, optimization algorithms, and framework implementations (MindSpore / TensorFlow / PyTorch).
• Huawei Cloud ModelArts: End-to-end AI development workflow including data labeling, model training, hyperparameter tuning, and API deployment.
• Huawei Cloud EI (Enterprise Intelligence) Services: Practical application of pre-trained APIs like OCR, Image Recognition, and Text To Speech (TTS).
